# OpenUI agent skills

Task-focused instructions for working in this repository. Load the skill that
matches your change; each one lists the canonical files, commands, and pitfalls
for its area.

| Skill                  | Use it for                                                               |
| ---------------------- | ------------------------------------------------------------------------ |
| `openui-architecture`  | Package boundaries, config flow, dependency direction, adding frameworks |
| `openui-components`    | Component APIs, framework parity, Tailwind styling, accessibility        |
| `openui-registry`      | Manifest edits, target tokens, `openui build`/`validate`, serving        |
| `openui-cli`           | Commands, flags, argument parsing, write safety, exit codes              |
| `openui-testing`       | Where to add tests, fixtures, compiler tests, `verify` failures          |
| `openui-documentation` | Canonical docs pages, LLM files, schema, docs site, link validation      |
| `openui-releases`      | Changesets, beta pre-release mode, versioning, manual publishing         |

Global rules are in `AGENTS.md` at the repository root.
